# tekartik_firebase_auth_flutter setup

Flutter (android, ios, macos, web) implementation of the `FirebaseAuth`
abstraction of `tekartik_firebase_auth`, backed by the official
`firebase_auth` plugin. App code only sees `FirebaseAuth`, `User` and
`UserCredential`; the native `FirebaseAuth` stays reachable through
`nativeInstance` for platform-only calls.

## Guidelines

* Import `package:tekartik_firebase_auth_flutter/auth_flutter.dart`. It
  re-exports `package:tekartik_firebase_auth/auth.dart` (`FirebaseAuth`,
  `User`, `UserCredential`, ...) and the Flutter API (`FirebaseAuthFlutter`,
  `FirebaseAuthServiceFlutter`; `AuthFlutter` and `AuthServiceFlutter` are
  compat typedefs).
* Initialize the native app first (`Firebase.initializeApp` from
  `firebase_core`, with the options generated by `flutterfire configure`),
  then get the tekartik app with `firebaseFlutter.app()` from
  `package:tekartik_firebase_flutter/firebase_flutter.dart`. When the
  platform config files are present, `firebaseFlutter.initializeAppAsync()`
  does the native initialization itself. Flutter only supports the default
  app (`app(name:)` throws).
* Create the auth once with `firebaseAuthServiceFlutter.auth(app)` and keep
  it: the service caches one instance per app. `authServiceFlutter` is the
  same service; the `authService` getter is deprecated. `FirebaseAuth.instance`
  and `app.auth()` (`TekartikFirebaseAuthFirebaseAppExt`) return the instance
  created for the default app, so they only work after that call.
* Cast to `FirebaseAuthFlutter` (`as FirebaseAuthFlutter`, or the `flutter`
  getter) when you need `nativeInstance`. The `nativeInstance` extension
  getter on any `FirebaseAuth` also works but throws on other backends.
* `currentUser` and `onCurrentUser` are fed by the native
  `authStateChanges()` stream (`supportsCurrentUser` is `true`). Listen to
  `onCurrentUser` in a `StreamBuilder`; call `reloadCurrentUser()` after an
  email verification to refresh `emailVerified`.
* Supported: `signInWithEmailAndPassword`, `createUserWithEmailAndPassword`,
  `signInAnonymously`, `signOut`, `sendEmailVerification` (current user),
  `sendPasswordResetEmail(email:)` (since 0.10.x) and the
  `signInOrUpWithEmailAndPassword` helper of `TekartikFirebaseAuthExt`.
* Not supported (throws `UnsupportedError`): `signIn(provider)`,
  `listUsers`, `getUser`, `getUserByEmail`, `verifyIdToken`
  (`supportsListUsers` is `false`). Federated providers (Google, Apple...)
  go through `nativeInstance.signInWithCredential` / `signInWithProvider`,
  or better through the screens of `tekartik_firebase_flutter_ui_auth`;
  `currentUser` follows automatically. Admin lookups belong to the node or
  admin backends, never to a client app.
* Read `UserCredential.user`, not `UserCredential.credential`: after an
  email/password sign in the native credential is `null` and the getter
  throws.
* The wrapped `User` implements `UserInfoWithIdToken`: cast it to call
  `getIdToken()` when a secured backend needs the token. `User.providerId` is
  always `null` here.
* Web: call `await auth.webSetIndexedDbPersistence()` right after creating
  the auth so the session survives page reloads. It is a no-op on other
  platforms and on other backends, so it is safe in shared code.
* Emulators: `auth.useAuthEmulator(host, port)` on a `FirebaseAuthFlutter`
  calls the native `useAuthEmulator(..., automaticHostMapping: true)`
  (`localhost` becomes `10.0.2.2` on the Android emulator). Call it right
  after creating the auth, before any sign in, and enable cleartext HTTP in
  the Android manifest. Do not use the legacy `useFirestoreEmulator` helper
  of `FirebaseAuthFlutterExtension`: despite its name it targets the auth
  emulator.
* Platform switch: `firebase_auth` only runs on web/android/ios/macos. On
  linux/windows use `tekartik_firebase_auth_rest` (`firebaseAuthServiceRest`)
  behind the same `FirebaseAuth` type; in tests use the local
  `tekartik_firebase_auth_sdb` / `tekartik_firebase_auth_sembast` backends.
* Dispose through `app.delete()`: it disposes the auth and cancels the
  `authStateChanges` subscription. Never construct `AuthFlutterImpl` or
  `AuthServiceFlutterImpl` yourself; they are not exported.
* The screens are not in this package: `tekartik_firebase_flutter_ui_auth`
  (native firebase_ui_auth screens, requires this backend) or
  `tekartik_firebase_ui_auth` (pure Flutter screens for any backend).

## Examples

### Initialization (production)

```dart
import 'package:firebase_core/firebase_core.dart' as native;
import 'package:tekartik_firebase_auth_flutter/auth_flutter.dart';
import 'package:tekartik_firebase_flutter/firebase_flutter.dart';

import 'firebase_options.dart'; // generated by `flutterfire configure`

late FirebaseApp globalFirebaseApp;
late FirebaseAuthFlutter globalFirebaseAuth;

Future<void> initFirebaseAuth() async {
  await native.Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  globalFirebaseApp = firebaseFlutter.app();
  globalFirebaseAuth =
      firebaseAuthServiceFlutter.auth(globalFirebaseApp) as FirebaseAuthFlutter;
  // Keep the session across page reloads on the web (no-op elsewhere).
  await globalFirebaseAuth.webSetIndexedDbPersistence();
}
```

### Auth emulator (debug flavor)

```dart
import 'package:tekartik_firebase_auth_flutter/auth_flutter.dart';

const emulatorHost = 'localhost';
const authEmulatorPort = 9099;

Future<void> useEmulator(FirebaseAuthFlutter auth) async {
  // Maps localhost to 10.0.2.2 on the Android emulator (automaticHostMapping).
  await auth.useAuthEmulator(emulatorHost, authEmulatorPort);
  // Same thing with access to the native options:
  // await auth.nativeInstance.useAuthEmulator(emulatorHost, authEmulatorPort,
  //     automaticHostMapping: true);
}
```

### Reacting to the current user, email/password

```dart
import 'package:flutter/material.dart';
import 'package:tekartik_firebase_auth_flutter/auth_flutter.dart';

class SignedInGate extends StatelessWidget {
  final FirebaseAuth auth;
  final Widget child;
  const SignedInGate({super.key, required this.auth, required this.child});

  @override
  Widget build(BuildContext context) {
    return StreamBuilder<User?>(
      stream: auth.onCurrentUser,
      builder: (context, snapshot) {
        var user = snapshot.data;
        if (user == null) {
          return TextButton(
            onPressed: () => auth.signInWithEmailAndPassword(
              email: 'test@example.com',
              password: 'password',
            ),
            child: const Text('Sign in'),
          );
        }
        return child;
      },
    );
  }
}

Future<void> forgotPassword(FirebaseAuth auth, String email) =>
    auth.sendPasswordResetEmail(email: email);
```

### Id token for a secured backend call

```dart
import 'package:tekartik_firebase_auth_flutter/auth_flutter.dart';

Future<String?> currentIdToken(FirebaseAuth auth) async {
  var user = auth.currentUser;
  if (user == null) {
    return null;
  }
  return (user as UserInfoWithIdToken).getIdToken(forceRefresh: false);
}
```
